# 伝統工芸品あて

西陣織・九谷焼・輪島塗・南部鉄器。経済産業大臣が指定する伝統的工芸品から100品目を選び、種類（焼き物・漆器・織物など）・読み方・どの都道府県か・特徴を当てる1日5問のゲーム。知らなくても遊べます。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/dento-kogei/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問当てられるか）、解いた種類が集まる「工芸帳」があります。
- 問題は「どの種類」「種類から品目」「読み方」「特徴から品目」「どの都道府県」「都道府県から品目」「書き方」「同じ都道府県」「近くの県から」「仲間はずれ」「数がいちばん多い」「数の多い順」。正解すると、その品目の札（読み・都道府県・種類）と「なぜ」と出典が出ます。
- 問題は732問（12種類）。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

- [経済産業省「伝統的工芸品指定品目一覧［都道府県別］」2026年10月22日現在（PDF）](https://www.meti.go.jp/files/000006438.pdf)：品目の名前・都道府県・都道府県ごとの数（全部で247品目）
- [経済産業省「伝統的工芸品」](https://www.meti.go.jp/policy/mono_info_service/mono/nichiyo-densan/index.html)：伝統的工芸品とは何か（伝統的工芸品産業の振興に関する法律）
- [伝統的工芸品産業振興協会「伝統的工芸品指定品目一覧・業種別」（PDF）](https://kyokai.kougeihin.jp/wp/wp-content/uploads/2025/10/shitei-Industry_20251027.pdf)：種類（業種）の分け方
- [伝統工芸 青山スクエア](https://kougeihin.jp/)：品目ごとのページ（`kougeihin.jp/craft/番号/`）の読み方・都道府県・特徴

結城紬（茨城・栃木）や本場大島紬（鹿児島・宮崎）など、2つの県にまたがる5品目は答えが1つにならないので問題に出しません。都道府県ごとの数は、それらを両方の県に数えた数です（足すと252）。名前に県の名前や「京」「江戸」「琉球」などが入る品目は、どの都道府県かを聞く問題には出しません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：画面を開くと文字（Google Fonts）のために Google へつなぐので、文字が端末に保存済みでも Google に IP アドレスが届くことがあります。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
